# Soil Quality Assessment System

## Overview

The Soil Quality Assessment System is a Python-based environmental analytics project designed to evaluate soil health and identify potential land degradation risks using multiple soil quality indicators.

The system calculates a Soil Quality Index (SQI) and Degradation Index (DI) by analyzing key soil parameters such as pH, organic matter, nutrient content, bulk density, erosion levels, and vegetation cover.

Based on the assessment results, the system classifies soil health, generates improvement recommendations, and produces visual reports to support sustainable land management.

---

## Features

### Soil Quality Assessment

* Calculates Soil Quality Index (SQI)
* Calculates Degradation Index (DI)
* Evaluates multiple soil health indicators

### Land Degradation Monitoring

* Detects degradation risks
* Classifies soil condition
* Identifies critical soil issues

### Recommendation Engine

* Generates soil improvement suggestions
* Recommends nutrient management practices
* Provides erosion and vegetation management guidance

### Data Visualization

* SQI comparison charts
* Indicator radar plots
* Organic Matter vs SQI analysis
* Soil degradation class distribution

## Soil Classification Levels

| SQI Range   | Classification      |
| ----------- | ------------------- |
| ≥ 0.80      | Healthy             |
| 0.60 – 0.79 | Moderately Healthy  |
| 0.40 – 0.59 | Moderately Degraded |
| 0.20 – 0.39 | Severely Degraded   |
| < 0.20      | Extremely Degraded  |
